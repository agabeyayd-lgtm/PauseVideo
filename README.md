# PauseVideo
PauseVideo

PauseVideo, Android telefonlarda geliştirilmesi hedeflenen, Python ve Google Colab ile başlayan bir YouTube Shorts video üretim projesidir.

Projenin amacı

- Kısa ve dikey videolar hazırlamak.
- Video işleme özellikleri eklemek.
- Yapay zekâ destekli, gerçekçi video üretimini araştırmak.
- Android cihazlarda kullanılabilecek bir uygulama geliştirmek.

Mevcut durum

- "app-release.apk": Android uygulama paketi.
- "README.md": Proje açıklaması.
- Python kaynak kodu ve video üretim özellikleri geliştirme aşamasındadır.

Google Colab ile başlama

1. https://colab.research.google.com/ adresini aç.
2. Yeni bir not defteri oluştur.
3. Python kodlarını hücrelere ekleyip çalıştır.
4. Çalışan kodu GitHub deposuna kaydet.

Geliştirme planı

1. Python kaynak kodunu oluşturmak.
2. Kodları Google Colab'da test etmek.
3. Video işleme ve dikey video çıktısı eklemek.
4. Yapay zekâ destekli video üretimi özelliklerini geliştirmek.
5. Android uygulamasını güncellemek ve test etmek.
